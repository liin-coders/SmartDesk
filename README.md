# Smart-Desk — Smart Business Management Dashboard

A modern, lightweight, and user-friendly business management dashboard built with **HTML5, CSS3, and Vanilla JavaScript**. Smart-Desk helps shopkeepers and small businesses manage customer records, credit sales (Udhar), payments received, and daily transactions from a simple, organized interface.

Designed with a premium UI, dark and light themes, and browser-based local storage, Smart-Desk provides a convenient way to maintain business records without requiring a complicated setup.

## ✨ Features

### 📊 Dashboard
- View total pending amounts and payments received.
- Track the total number of customers and today's entries.
- View a last-seven-days transaction overview.
- Identify customers with the highest pending balances.
- Access quick actions from the home screen.

### 👥 Customer Management
- Add and manage customer records.
- Search customers by name or phone number.
- Filter customers by all records, pending balances, or cleared balances.
- View customer transaction history.
- Quickly add entries for individual customers.

### 📒 Money Book
- Maintain a complete transaction history.
- Record credit sales (Udhar).
- Record payments received.
- Search and filter transaction entries.
- Edit incorrect transaction details.
- Automatically update pending and received totals.

### 🧮 Built-in Calculator
- Perform everyday calculations.
- Use basic arithmetic operations.
- Add calculated amounts directly as transaction entries.

### 📤 Share & Export
- Export business records to an Excel-compatible file.
- Copy data for use in Google Sheets.
- Print business summaries or save them as PDF using the browser's print dialog.

### ⚙️ Settings & Personalization
- Customize your business name and business type.
- Switch between dark mode and light mode.
- Change the interface language using the available language options.
- Download a backup of your business data.
- Restore previously saved data from a backup file.
- Clear locally stored application data when needed.

### 💾 Local Storage
- Save records in the browser's local storage.
- Retain saved data when the application is reopened in the same browser and browser profile.
- Use the application without setting up a database server.
- Keep business records stored locally on the device.

### 🌐 Online & Offline Support
- Includes an online/offline status indicator.
- Designed for convenient use without requiring a permanent internet connection.
- Local data management does not require a cloud account or backend server.

> **Important:** Local Storage keeps data in the current browser on the current device. It does not automatically synchronize records between multiple devices or users. Use the backup and restore features to transfer data manually.

## 🛠️ Technologies Used

- **HTML5** — Application structure and content.
- **CSS3** — Layout, responsive design, themes, and styling.
- **Vanilla JavaScript** — Application logic, transactions, calculations, and interactions.
- **Browser Local Storage** — Persistent local data storage.
- **Browser APIs** — Supported export, clipboard, printing, and file operations.

No frontend framework is required.

## 🚀 Getting Started

### Run in VS Code

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open it in your browser.

For a convenient development workflow, you can use the **Live Server** extension in VS Code.

1. Install Live Server from the Extensions panel.
2. Right-click `index.html`.
3. Select **Open with Live Server**.

You can also open `index.html` directly in a modern browser if the application does not depend on server-only features.

### Run Locally

If you have Git installed, run:

```bash
git clone YOUR_REPOSITORY_URL
cd Khata-Desk
```

Then open the project folder in VS Code and launch `index.html`.

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

## 🔐 Privacy & Data Safety

- Business data is stored locally in the browser.
- No backend database or cloud synchronization is included by default.
- Clearing browser data, changing browsers, or using another device may make existing records unavailable.
- Export backups regularly to reduce the risk of data loss.
- Keep backup files secure because they may contain customer names, phone numbers, and financial records.

Smart-Desk should not be treated as a substitute for a secure, multi-user cloud accounting system.
